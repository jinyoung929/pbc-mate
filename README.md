# PBC Mate

삼일 연수 과제용 MVP. 회계감사 PBC(Prepared By Client) 자료 요청을 추적하고,
미제출 건에 대한 독촉·보완 요청 메일 문안을 만들어 주는 웹 도구.

> 상태: MVP 핵심 플로우 구현 완료 · 최종 QA 전

## 주요 기능

- **필요일 기준 우선순위** — 남은 날로 위험도(지연 · 2일 이내 · 3~7일 · 8일 이상)를 나누고, 필요일순/경과일순으로 정렬
- **단건 독촉 + 톤 추천** — 천사 · 정중 · 단호 · 매니저 참조 4단계. 남은 날과 경과일로 기본 톤을 추천하고 슬라이더로 변경
- **담당자별 묶음 독촉** — 같은 담당자의 미완료 자료를 메일 한 통으로 (보완 요청 자료는 제외)
- **보완 요청** — 기준일 상이 · 서명 누락 · 일부 항목 누락 · 파일 오류 사유별 재요청 메일
- **발송 시점 안내** — 필요일 긴급도 > 요일·시간 순으로 "지금 / 다음 영업일 오전" 추천 (예약 발송은 하지 않음)
- **자료 추가** — 한 건씩 입력, 또는 엑셀 행 붙여넣기(탭 구분, 미리보기 후 일괄 저장). 새 자료는 미회신으로 시작
- **상태 변경 · 수령 처리** — 자료 화면에서 일부 수령 · 보완 요청 · 완료로 변경. 처음 받은 날이 수령일로 기록됨
- **주간 현황 / CSV** — 상태별 집계, 담당자별 현황, 자료 목록. 공유용 텍스트 복사와 CSV 내려받기
- **일정** — 월 달력에 자료 필요일과 직접 만든 일정을 함께 표시. 메일의 날짜를 끌어다 캘린더에 추가, 달력에서 끌어 날짜 이동(필요일도 바뀜). 할 일은 완료 · 진행중 · 진행예정으로 구분

메일은 모두 **클립보드 복사**까지만 한다. 실제 발송은 아웃룩에서 사용자가 한다.
데이터는 브라우저 localStorage에만 저장된다.

## 실행

빌드 과정 없음. 정적 파일 서버로 `src/`를 열면 된다.

```bash
python3 -m http.server 8000 --directory src
```

→ http://localhost:8000

(ES 모듈을 쓰기 때문에 `index.html`을 파일로 직접 열면 동작하지 않는다.)

- "예시 자료로 시작"으로 불러온 자료는 **시연 기준일 2027-01-14**(2026 기말감사 현장 기간)로 고정돼, 언제 열어도 같은 화면이 나온다.
  첫 화면에서 클라이언트명·감사명을 넣고 "직접 추가"로 시작하면 실제 오늘 날짜로 계산된다.
- `?today=2026-10-03`처럼 붙이면 기준일을 직접 지정할 수 있다 (시연 기준일보다 우선).
- `?now=2026-10-02T17:20`처럼 붙이면 날짜와 시각을 함께 지정한다. 발송 시점 안내(금요일 늦은 시간 → 월요일 오전 추천)를 재현할 때 쓴다.
- 브라우저 콘솔에서 `pbc.reset()`을 실행하면 저장된 자료를 지우고 첫 실행 화면으로 돌아간다.

## 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 화면 | HTML + CSS + Vanilla JS (ES 모듈) | 빌드·의존성 없이 바로 실행 |
| 데이터 | `localStorage` | 서버 없이 MVP 동작 확인 |
| 테스트 | Node 내장 `node:test` | 추가 설치 없음 |
| 실행 | `python3 -m http.server` | macOS 기본 탑재 |

## 디자인 레퍼런스

`reference/pbc-mate-ui-reference.html`을 브라우저로 열면 화면 17개를 볼 수 있다.

1. 대시보드 (필요일순 / 경과일순 / 모바일)
2. 단건 독촉 (정중 / 단호 / 매니저 참조 / 복사 완료 / 모바일)
3. 묶음 독촉
4. 보완 요청 (기준일 상이 / 서명 누락)
5. 발송 시점 안내
6. 자료 추가 (한 건씩 / 엑셀 붙여넣기)
7. 주간 현황 보고
8. 빈 상태 (첫 실행)
9. 공통 요소
